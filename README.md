# 🧮 Smart Calculator

A simple desktop calculator built with Python and Tkinter.

This project was built from scratch while learning Python, GUI development, file handling, and project organization.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal numbers
- 🧹 Clear button
- 📜 Calculation history
- 🖥️ Graphical User Interface
- 💾 History saved to a text file

## 🛠️ Technologies Used

- Python
- Tkinter
- PyInstaller
